 Music Player

An interactive audio player built to explore the Web Audio API and reactive UI patterns.

## Features
-  Core playback controls (play/pause/next/previous)
-  Real-time progress tracking with time display
-  Volume controls with mute functionality
-  Shuffle and repeat playback modes
-  Dynamic album art display
-  External music API integration
-  Background color sync with album artwork

## Tech Stack
- HTML5 Audio API
- Vanilla JavaScript 
- CSS3 animations

## Learning Goals
- Master Audio API implementation
- Handle UI state synchronization
- Work with external APIs
- Build responsive, interactive controls
